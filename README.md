## 📖 Overview

**DBList** is a modern, high-performance web directory built for Discord server owners, community managers, and bot developers. It connects thousands of Discord communities with top-tier bots for music, moderation, economy, anime, utility, and gaming.

With real-time analytics, automated OpenGraph image generation, responsive markdown profiles, dynamic SEO sitemaps, and authentic community reviews, DBList provides a seamless platform for discovering and showcasing Discord bots.

## 🔥 Key Platform Features

### 🔍 Instant Search & Multi-Tag Discovery
- **Tag-Based Exploration**: Instantly filter across `Music`, `Moderation`, `Economy`, `Anime`, `Gaming`, `Utility`, `24/7`, and `Dashboard`.
- **Fast Fuzzy Search**: Search bots by name, prefix, keywords, or short description.

### 🗳️ 12-Hour Voting Engine & Cooldowns
- User-friendly upvoting mechanism with strict cooldown tracking per user.
- Live leaderboard calculation for Top Rated and Trending Discord bots.

### ⭐ Authentic Community Reviews & Star Ratings
- Interactive 5-star rating system with real user authentication.
- Detailed score breakdown, percentage recommendation bars, and developer responses.

### 📊 Real-Time Developer Analytics Dashboard
- Dedicated analytics portal (`/bot/:botId/analytics`) for verified bot owners.
- Detailed traffic breakdown: Total Pageviews vs Unique Visitors (IPs), Country Geolocation, Referrer Sources, and Device / Client detection (Mobile vs Desktop vs Discord in-app browser).

### 🏷️ Dynamic Canvas OpenGraph Banners
- Server-side Canvas image generation (`/api/bot/:botId/og-image.png` & `/api/tag/:tag/og-image.png`).
- High-res social previews optimized for Discord embed shares, Twitter Cards, and search results.

### 🚀 Search Engine Optimization (SEO Ready)
- **Dynamic XML Sitemap** (`/sitemap.xml`) with Google Image extensions and bot lastmod tracking.
- **RSS 2.0 Feed** (`/rss.xml`) for instant search engine indexing.
- Comprehensive Schema.org (`SoftwareApplication` & `AggregateRating`) JSON-LD integration.

## 🛠️ Architecture & Tech Stack

| Layer | Technology |
| :--- | :--- |
| **Backend Runtime** | [Node.js](https://nodejs.org) (v18+) with [Express.js](https://expressjs.com) |
| **Database & ODM** | [MongoDB](https://www.mongodb.com) with [Mongoose](https://mongoosejs.com) |
| **Authentication** | [Passport.js](https://www.passportjs.org) with Discord OAuth2 Strategy |
| **Template Engine** | [EJS](https://ejs.co) (Embedded JavaScript templates) with SSR |
| **Styling & UI** | Custom Vanilla CSS (Responsive design, dark theme, fluid typography) |
| **Icons & Media** | [FontAwesome 6](https://fontawesome.com), Canvas API for dynamic OG images |
